# Professional UI/UX refinement

## Goal
Polish the existing PlantãoPro AC experience without changing business rules, routes, data, or the established tactical identity.

## Scope
- Refine the public home screen and authenticated agent dashboard as the visual baseline.
- Standardize spacing, section widths, typography hierarchy, card treatment, borders, shadows, and interaction feedback.
- Improve mobile composition, touch targets, safe-area behavior, and dense layouts at narrow widths.
- Strengthen loading, empty, selected, active, disabled, and focus states using existing semantic tokens.
- Preserve Portuguese copy, current imagery, dark institutional palette, and all existing actions.

## Implementation
1. Tighten global visual foundations in the shared styles: consistent radii, surface depth, focus rings, motion timing, and reduced-motion behavior.
2. Rework the public home composition so the fixed header, operational banner, metrics, and team selection share one clear grid and spacing rhythm.
3. Polish the signed-in agent dashboard header, next-shift area, KPI row, weekly schedule, quick actions, swaps, and recent activity for clearer hierarchy and responsive flow.
4. Replace raw interactive elements in touched areas with the project button patterns where appropriate, while preserving behavior.
5. Improve shared skeleton and empty-state presentation to reduce layout shift and make waiting states feel intentional.

## Validation
- Run the project’s existing checks.
- Review the public home at desktop and mobile widths.
- Review the authenticated dashboard when an authenticated preview session is available.
- Check overflow, text wrapping, focus visibility, touch targets, and reduced-motion behavior.
